Циферки

Помощник для количественного анализа: расчёт, проверка допущений и пояснения по методологии

1. Данные

Форматы: CSV или Excel (.xlsx). Первая строка — названия столбцов, десятичный разделитель — точка.

2. Настройка анализа

Процедура: описательные статистики → нормальность (Шапиро–Уилк) → однородность дисперсий (Левен) → выбор теста (Стьюдент / Уэлч / Манн–Уитни) → размер эффекта.
